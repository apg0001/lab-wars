# 랩워즈 기획서

> 교수님의 잡무에 연구실이 무너지기 직전이다. 대학원생들이 들고일어났다.

## 1. 한 줄 소개

모바일 웹에서 가로 화면으로 플레이하는 **횡스크롤 라인 디펜스** 게임입니다. 왼쪽은 우리 **연구실**, 오른쪽은 **교수실**입니다. 카페인을 모아 연구실 사람들을 내보내고, 교수님이 쏟아내는 잡무 군단을 밀어내 교수실을 함락하면 승리합니다.

## 2. 핵심 루프

1. **전투**: 카페인으로 아군을 소환하면 아군이 자동으로 전진하며 싸웁니다. 플레이어는 어떤 유닛을 언제 뽑을지, 커피머신에 투자할지 고르고, 멘탈을 써서 스킬을 발동합니다.
2. **보상**: 승리하면 연구비와 별(1~3개)을 받습니다. 패배해도 그 판에서 처치한 적의 연구비는 받습니다.
3. **성장**: 연구비로 유닛 레벨과 연구실 시설을 올립니다.
4. **진행**: 다음 스테이지와 챕터를 열고, 챕터마다 새 유닛과 스킬을 해금합니다.

## 3. 재화

| 재화 | 범위 | 얻는 법 | 쓰는 곳 |
|---|---|---|---|
| ☕ 카페인 | 전투 중 (판마다 초기화) | 시간에 따라 자동 충전 (기본 5/초, 시작 30, 최대 100) | 유닛 소환 |
| 🧠 멘탈 | 전투 중 (판마다 초기화) | 시간에 따라 자동 충전 (기본 1.5/초, 최대 100) | 스킬 발동 |
| 💰 연구비 | 영구 저장 | 스테이지 클리어 보상, 적 처치 | 유닛·시설 업그레이드, 심사 결과(꾸미기 뽑기) |
| ⭐ 별 | 영구 저장 | 클리어 시 연구실 남은 체력 70% 이상 3개, 35% 이상 2개, 그 외 1개 | 진행도 표시, 첫 클리어 보상 배율 |

**전투 중 커피머신 업그레이드**: 전투 중에 카페인을 써서 커피머신 단계를 올릴 수 있습니다 (1~6단계, 판이 끝나면 초기화). 단계마다 카페인 최대치 +25%, 충전 속도 +20%이고, 다음 단계 비용은 30 → 50 → 75 → 105 → 140 카페인입니다. 바로 유닛을 뽑을지, 경제에 투자해 후반을 노릴지 고르는 선택지입니다. 연구실 시설의 커피머신·텀블러(영구 강화)와 곱으로 적용됩니다.

**클리어 보상**: 스테이지 기본 연구비 × (0.6 + 0.2 × 별 수). 첫 클리어는 전액, 다시 깨면 50%를 줍니다 (막히면 앞 스테이지를 돌며 성장할 수 있게).

### 지상과 공중

- 근접 유닛은 **지상만** 공격합니다. 공중 적은 머리 위로 지나갑니다.
- 원거리 유닛(사거리 100 이상), 포탑, 스킬은 **공중도** 공격합니다.
- 공중 유닛은 지상 유닛에게 길을 막히지 않습니다.

## 4-1. 성장: 레벨과 진화

- 모든 유닛은 **3단계로 진화**합니다. 단계마다 레벨 상한이 있습니다 (1단계 Lv5, 2단계 Lv10, 3단계 Lv15).
- **레벨업**: 레벨마다 HP·공격 +8%. 비용은 `소환 비용 × 6 × 1.33^(현재 레벨 − 1)` 연구비입니다.
- **진화**: 레벨 상한에 도달하면 진화할 수 있습니다. 진화하면 HP·공격 ×1.5가 되고, 외형과 이름이 바뀝니다. 비용은 2단계 `소환 비용 × 45`, 3단계 `소환 비용 × 135` 연구비입니다.

| 기본 | 2단계 | 3단계 |
|---|---|---|
| 학부 ○○ | 석사 ○○ | 박사 ○○ |
| 연구용 드론 | 쿼드콥터 | 자율비행 드론 |
| GPU 서버 | GPU 클러스터 | 슈퍼컴퓨터 |
| 클로디 | 클로디 프로 | 클로디 맥스 |
| 코덱시 | 코덱시 터보 | 코덱시 울트라 |
| 재미나이 | 재미나이 플러스 | 재미나이 울트라 |

**🚨 교수님 비상 소집** — 교수실 HP가 75%, 50%, 25% 아래로 처음 떨어질 때마다 한 번씩 일어납니다. 교수실 앞 300 안의 아군에게 `포탑 공격력 × 2 + 최대 HP의 12%` 피해와 넉백을 주고, 러시의 절반만큼 지원군을 부릅니다. 물량을 쌓아 건물에 붙어 녹이는 전략을 끊기 위한 장치입니다.

**보스 호통** — 보스의 HP가 66%, 33% 아래로 처음 떨어질 때마다 한 번씩 보스가 호통을 칩니다. 전장의 모든 아군이 1.2초 동안 기절(이동·공격 불가, 머리 위에 어지러움 표시)하고 약 70 뒤로 밀려납니다. 피해는 없습니다. 화면이 붉게 번쩍이지만 흔들리지는 않습니다. 최종 보스 총장님은 75%·50%·25%에서 세 번, 1.3초 기절·80 밀어내기로 더 셉니다. 보스마다 `rage`로 따로 정할 수 있습니다.

**시간 제한** — 일반 스테이지(외전 포함) 5분, 보스 스테이지 6분, 무한 모드 8분 (`StageDef.timeLimit`). 전투 상단 시계는 남은 시간을 보여 주고, 1분 남으면 "퇴근 1분 전!" 배너, 30초 이하면 빨갛게 깜빡입니다. 시간이 다 되면 교수실을 못 무너뜨린 것으로 보고 패배합니다 ("야근 확정… 시간 초과"). 밸런스 봇의 판 길이 상한도 이 제한을 따릅니다.

## 6. 연구실 무기, 포탑, 스킬

**자동 포탑**: 양쪽 건물에 기본 공격 포탑이 달려 있어 사거리 안의 적을 자동으로 공격합니다 (지상·공중 모두).

| 포탑 | 소속 | 공격 | 사거리 | 간격 |
|---|---|---|---|---|
| 자동 프린터 포탑 | 연구실 | 20 (피해 강화 가능) | 300 (사거리 강화 가능, 전장 바닥에 표시) | 0.8초 |
| 레이저 포인터 포탑 | 교수실 | 10 (스테이지에 따라 증가) | 260 | 1.2초 |

**넉백(군중 제어)**: 범위·강타 공격은 확률로 맞은 적을 뒤로 밀어내고 0.4초 동안 이동·공격을 막습니다. 보스는 면역입니다.

### 6-1. 학회 경품 추첨 (전투 중 카드)

운 요소. 효과는 **그 판에만** 적용되어 성장·순위표에는 영향이 없습니다. 무한 모드에도 적용됩니다.

- **시점**: 잡무 러시로 나온 적을 모두 쓰러뜨리면(러시를 버텨 내면) 추첨합니다. 러시를 못 버텨도 마지막 추첨(또는 시작)에서 80초가 지나면 추첨합니다. 시작 30초 전에는 없고, 추첨 사이 최소 45초, 한 판에 최대 3번.
- **진행**: 뒤집힌 봉투 3장이 차례로 뒤집히고, 한 장을 고릅니다 (단축키 1/2/3). 고르는 동안 전투가 멈춥니다.
- **추첨 난수**: 전투 시드에서 따로 만든 난수를 써서 같은 시드면 같은 카드가 나옵니다. 의미 없는 카드(랩장이 없을 때 확성기, 커피머신 최고 단계일 때 무상 수리)는 빠집니다.
- **등급 확률(장마다)**: 일반 61% · 희귀 26% · 전설 8% · 저주 5%. 적용 중인 효과는 전장 위 칩으로 보입니다.
- **봇**: 가장 높은 등급을 고르고 저주는 피합니다.

| 등급 | 카드 | 효과 |
|---|---|---|
| 일반 | 아이스 아메리카노 리필 | 카페인 +40 즉시 |
| 일반 | 조교 대타 투입 | 모든 동료 재소환 대기 초기화 |
| 일반 | 토너 새로 갈기 | 프린터 포탑 피해 +25% |

| `revive: { hpRatio }` | 1회 부활 |
| `fieldStrike: { dmg, every }` | 전장의 모든 적에게 주기 타격 |
| `chain: { jumps, range, falloff }` | 연쇄 번개: 맞힌 적에서 range 안의 가장 가까운 적으로 jumps번 튐 (튈 때마다 ×falloff, 자기 상태 이상도 건다) |
| `armorShred: { mul, dur }` | 방어 깎기: 맞힌 적이 받는 피해 ×mul (다시 맞으면 시간 갱신·더 센 쪽), 깨진 방패 아이콘 |
| `knockup: { chance, dur }` | 띄우기: 확률로 dur초 공중에 떠서 기절 (보스 면역) |
| `lifesteal: ratio` | 흡혈: 실제로 깎은 HP의 ratio만큼 자기 회복 |
| `airMul: n` | 대공 배율: 공중 적에게 피해 ×n |
| `stunField: { every, radius, dur }` | 기절 장판: 주기마다 반경 안 상대 기절 (보스 40%), 상대가 없으면 기다림. 아군(EMP)·적(블루스크린) 공용 |
| `turret.speed` | 포탑 스펙에 속도를 주면 제자리 포탑 대신 앞으로 걸어가는 졸개 (라우터의 패킷) |
| `split: { count, hpRatio, scale }` | (적) 분열: 쓰러지면 작은 같은 적 count마리. 갈라진 쪽은 다시 안 갈라지고 처치 카페인 절반 |
| `grow: { rate, max }` | (적) 성장: 초당 최대 HP ×rate씩, max배까지. 늘어난 만큼 HP도 차고 몸도 커짐 |
| `respawn: { hpRatio }` | (적) 재출현: 처음 쓰러지면 보상 없이 출발점으로 돌아가 HP×hpRatio로 다시 옴 |
| `caffeineDrain: n` | (적) 카페인 흡수: 맞힐 때마다 플레이어 카페인 −n |

레벨·진화 배율(`unitStats`)은 화상 dps, 폭발·전장 타격 피해, 보호막 양, 회복량, 포탑 HP·공격에도 곱해집니다 (연쇄 비율·흡혈 비율·기절 시간은 그대로). 상태 이상은 전투 화면에 불꽃·달팽이·얼음·방패·깨진 방패 아이콘과 얼음 덩어리·보호막 방울로, 띄우기는 포물선 점프로, 연쇄 번개는 적 사이 지그재그로 보입니다.

전투에서 장비 그림은 학생 유닛과 키가 비슷하도록 1.2배로 그립니다 (`GEAR_DRAW_SCALE`, 판정 크기는 그대로).

## 9. 화면과 조작 (모바일 우선)

- **가로 화면 기준 비율(16:9)**. 세로로 들면 세로 전용 배치로 바뀝니다: 전투는 위쪽에 전장 띠(하늘·바닥을 잘라 확대), 아래쪽에 자원 바·스킬·소환 버튼 격자.
- 전장은 화면보다 넓고, **좌우로 드래그해서 시점 이동**합니다. 📚 폭격 스킬은 버튼을 누른 뒤 전장을 탭해 조준합니다.
- 하단: 유닛 소환 버튼(비용·재사용 대기 표시), 우측: 스킬 버튼, 상단: 카페인·멘탈 바, 양쪽 건물 HP, 일시정지와 배속(1x → 2x → 3x, 마지막 배속 기억).
- **처음 하는 사람 안내**: 새 저장으로 1-1을 처음 할 때(스토리 장면 뒤) 전투를 멈추고 말풍선 5단계(목표 → 소환 → 카페인·커피머신 → 스킬 → 시점 이동)를 보여 줍니다. 다음·건너뛰기 가능. 편성을 아직 안 열어 본 사람은 동료가 둘 이상일 때 지도에서 한 번 편성 안내가 뜹니다. 둘 다 `seen`에 `guide:tutorial`·`guide:squad`로 남겨 다시 뜨지 않습니다 (`src/sim/guide.ts`, `src/ui/tutorial.ts`).
- 진행도는 기기(`localStorage`) 또는 계정 서버에 저장합니다.
- **소리**: 음원 파일 없이 Web Audio로 합성한 배경음악(로비·전투·보스)과 효과음. 배경음악·효과음 각각 켜기/끄기와 볼륨 조절.
- **연출**: 피격 번쩍임과 찌그러짐, 근접 런지, 처치 시 날아감, 파편·불꽃, 히트스톱 (화면 흔들림은 어지러워서 뺐습니다).

## 10. 아트 방향

- 모든 캐릭터는 이 프로젝트에서 새로 디자인한 **둥근 2등신 낙서풍**입니다. 이미지 파일 없이 코드로 그립니다.
